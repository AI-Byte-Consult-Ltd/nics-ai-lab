# NICS Trading: инструкция для ноутбука (Windows)

Версия 0.7.1, 20.11.2026. Всё делается один раз. Потом модель учится сама каждую ночь.

## 0. Что это за репозиторий и что с ним делать

`AI-Byte-Consult-Ltd/nics-ai-lab` хранит только **код** наших моделей: архитектуру,
обучение, методики, скрипты. **Весов и данных в нём нет и не будет.** Они живут только
на ноутбуке, в папках `data\` и `experiments\`, и git их не видит.

Что с ним делать:
- **Работать с клоном, а не с архивом.** ZIP-архив не обновляется. Клон обновляется
  одной командой `git pull`, а ночной цикл сам делает `git pull` перед обучением.
  Поэтому мои правки доходят до ноутбука без вашего участия.
- **Сделать репозиторий приватным (рекомендую).** Лицензия теперь коммерческая, и
  бесплатное использование запрещено. Но пока репозиторий публичный, код видят все.
  GitHub → репозиторий → Settings → General → внизу Danger Zone → Change visibility →
  Private. Ничего не сломается: ноутбук и я работаем через вашу учётную запись.
- **Не класть в репозиторий ключи, `data\` и `experiments\`.** `.gitignore` уже их
  исключает.

## 1. Установка (один раз, ~15 минут)

1. Поставьте Git: https://git-scm.com/download/win (все галочки по умолчанию).
2. Поставьте Python 3.11 или 3.12 (64-bit): https://www.python.org/downloads/windows/.
   При установке отметьте **Add python.exe to PATH**.
3. Откройте PowerShell или «Командную строку» (Win+R → `cmd`) и выполните:

```
mkdir C:\NICS
cd C:\NICS
git clone https://github.com/AI-Byte-Consult-Ltd/nics-ai-lab.git
cd nics-ai-lab
scripts\windows\setup.bat
```

`setup.bat` создаёт окружение `venv`, ставит библиотеки (PyTorch для процессора,
MetaTrader5) и запускает проверку. В конце должно быть `SMOKE TEST PASSED` и `Setup OK`.
Если вместо этого `SETUP FAILED`, пришлите мне текст из окна.

Все команды ниже запускают Python из папки `venv` напрямую:
`.\venv\Scripts\python.exe ...`. Так работает и в PowerShell, и в cmd, и не нужна
команда `activate` (PowerShell её по умолчанию блокирует).

Старый скачанный архив можно удалить. Если старая папка `nics-ai-lab` с весами
Language/Vision уже есть, не удаляйте её: в ней `experiments\` с весами двух первых
моделей. Скопируйте эту папку `experiments\` в новый клон.

## 2. Ключ доступа к данным (один раз)

Ключ из n8n «[41 LAB] Market Data Export» у вас уже есть. Сохраните его в Windows:

```
setx NICS_DATA_URL https://n8n.aibyteconsult.com/webhook/nics-lab-market-export
setx NICS_DATA_KEY ВАШ_КЛЮЧ
```

**Закройте окно и откройте новое**: `setx` действует только в новых окнах. Если
запустить обучение в том же окне, программа ключа не увидит. Ключ никому не пересылайте и в файлы не вставляйте.

## 3. Первый запуск вручную

```
cd C:\NICS\nics-ai-lab
.\venv\Scripts\python.exe scripts\self_learn.py --from-scratch
```

Что произойдёт:
1. Скачаются все наши данные: свечи Vantage MT5 всех таймфреймов, все сигналы с
   итогами, события сигналов, теневые стратегии и календарь. Плюс публичная история:
   D1/W1 (Yahoo, Kraken) и часовые свечи Dukascopy с 2008 года по форексу, металлам,
   нефти, индексам и BTC. Dukascopy в первый раз качается долго (до 1–2 часов,
   примерно один файл в секунду), потом берётся из `data\cache\` и докачиваются
   только новые месяцы.
2. Модель обучится с нуля на всём этом. Сюда входят методики: диапазон с двух сторон,
   пробой, откат к EMA и отбой от уровня. Их сделки строятся на истории, а результат
   проверяется по свечам.
3. Лучшая модель станет «чемпионом»: `experiments\trading\nics-trading-nano\champion\`.

Время зависит от ноутбука. Я оцениваю в 20–60 минут, но не проверял на вашем
железе. Окно не закрывайте.

## 4. Наши сделки из MT5 (по разу на каждый счёт, потом раз в месяц)

Откройте терминал MT5, войдите в проп-счёт и выполните:

```
.\venv\Scripts\python.exe scripts\fetch_mt5_history.py --snapshot data\market\ДАТА --label prop
```

`ДАТА` — сегодняшняя папка в `data\market\`, например `2026-11-19`. Потом войдите в
терминале в Vantage и повторите команду с `--label vantage`. Для алго-счёта используйте
`--label algo`. Номер счёта в файл не записывается. Эти сделки сами переносятся в
каждый следующий ночной снимок, повторять нужно только для новых сделок.

## 5. Включить самообучение (один раз)

```
scripts\windows\install_tasks.bat
```

Создаются три задачи Windows:
- **NICS Trading self-learning**, каждую ночь в 03:30. Она делает `git pull`, скачивает
  свежие данные, дообучает чемпиона и раз в неделю обучает модель с нуля. Затем она
  **сравнивает модели на одних и тех же новых данных** (на проверочной части).
  Новая модель заменяет чемпиона только если она лучше. Иначе остаётся старая.
  Тестовая часть в выборе не участвует. Она нужна только для честного отчёта.
- **NICS Trading shadow score**, каждый час. Чемпион оценивает новые сигналы сканера:
  вероятность, что TP1 будет раньше стопа. Оценка только записывается в файл, никому
  не отправляется и на торговлю не влияет. На следующую ночь эти оценки сверяются с
  реальными итогами. Это честная проверка «вперёд»: модель ставила оценку, когда итог
  ещё не был известен.
- **NICS Trading opinion**, каждые 2 минуты (с версии 0.8.0). Ноутбук проверяет, были
  ли новые сигналы, **отправленные пользователям**. Если были, модель оценивает каждый
  сигнал и его зеркальный вариант и шлёт в Telegram **только Александру**: согласна
  или против, и шанс дойти до TP1 раньше стопа по обеим сторонам. Каждый сигнал
  получает мнение один раз (список отвеченных: `shadow\opinions_sent.csv`). На сигнал,
  пользователей, бота и советника это не влияет. Работает, пока ноутбук включён;
  сигналы старше 3 часов не оцениваются. Окно консоли не появляется.

Ноутбук **не обязан** быть включён всегда:
- если в 03:30 ноутбук выключен или спит, ночное обучение запустится само, как только
  вы его включите и появится интернет;
- пропущенные часы оценки сигналов просто пропускаются;
- обе задачи ждут интернет и работают и от батареи.

Пока идёт обучение (обычно до часа), ноутбук не выключайте. Если выключить посреди
обучения, ничего не сломается: чемпион останется прежним, следующая попытка будет
при следующем запуске.

Убрать задачи: `scripts\windows\remove_tasks.bat`.

## 6. Что присылать мне

С версии 0.7.1 присылать файлы вручную больше не нужно: после каждого ночного цикла
ноутбук сам отправляет итог ночи и итог «сканер против модели» на ваш личный рабочий
стол (страница в n8n, ссылка у вас в Telegram). Уходят только цифры: веса, данные и
ключи остаются на ноутбуке. Если ноутбук был без интернета, отправка повторится
следующей ночью. Новая версия скачивается сама (ночная задача делает `git pull`).

Если что-то пойдёт не так, файлы можно по-прежнему прислать вручную из
`experiments\trading\nics-trading-nano\`:
- `self_learn_last.json`: итог последней ночи (чемпион, претенденты, кто победил,
  проверка вперёд);
- `champion\metrics.json`: метрики чемпиона по таймфреймам и видам сигналов.

Плюс третий файл: `experiments\trading\nics-trading-nano\shadow\direction_last.txt`.
Это итог дня «сканер против модели». Каждый час модель в тени выбирает своё
направление по каждому сигналу сканера: она оценивает сигнал и его зеркальный
вариант (то же место входа, те же расстояния до стопа и тейка, обратное
направление). На торговлю и советника это не влияет. Каждую ночь считается, кто
дал лучший результат за прошлый день: в R, в R на сигнал и в $ при риске 100 $ на
сигнал. С версии 0.8.0 главный итог считается **только по сигналам, отправленным
пользователям**. Остальные записи сканера (он записывает одну и ту же идею заново
на каждом скане) идут отдельной строкой, без повторов. История по дням лежит в
`shadow\direction_daily.csv`.

С версии 0.9.0 там же лежит `shadow\rules_last.txt`: правила из трейдерских книг, которые
пока проверяются в тени (модель на них ещё не учится). Для каждого правила: результат
вперёд с даты добавления (главное), на нашей истории и на публичной истории. Полный
список правил и решений: `docs\rules_registry.md`.

Журналы лежат в `logs\self_learn.txt`, `logs\shadow_score.txt` и `logs\opinion.txt`.

## 7. Где веса и как их не потерять

- Текущий чемпион: `experiments\trading\nics-trading-nano\champion\model.safetensors`.
- История смен чемпиона: `champion_history.jsonl`.

**Делайте резервную копию** папки `experiments\` раз в неделю на внешний диск или в
облако. Папка `nics-llm` пропала вместе со старым ноутбуком, повторять это не надо.
Если подключим Cloudflare R2, копирование настрою автоматически.

## 8. Как научить модель новой методике

Опишите мне методику словами: вход, стоп, тейк и условия. Я добавлю её в
`src/nics/market/methods.py`. Ночью ноутбук сделает `git pull`, построит сделки
методики на всей истории, проверит их итоги по свечам, и модель начнёт их учитывать.
Методики прогоняются и по нашим свечам, и по 18 годам публичной истории. Сделки
на публичной истории идут только в обучение, а выбор лучшей модели делается только
по нашим сигналам. Название методики модель видит как отдельный признак, так что она учится различать,
какая методика в каком рынке работает.

## 9. Что модель делает и чего не делает

Модель делает:
- учится на всех свечах (M1, M5, M15, H1, H4, публичные H1/H4 с 2008 года и D1/W1) по всем 27
  инструментам;
- видит индикаторы (RSI, EMA 20/50/200, MACD, Боллинджер, стохастик, ADX), уровни
  и каналы, свечные паттерны (поглощения, пин-бары, доджи, внутренние и внешние бары);
- учится на всех сигналах сканера с их итогами, включая уверенность, оценки, TP2/TP3,
  версию стратегии и запас хода по ATR, а также на теневых стратегиях, сделках
  советника, наших сделках и методиках;
- сама дообучается каждую ночь и оставляет лучшую версию.

Модель не делает:
- не торгует и не шлёт сигналы. Подключение к сканеру — отдельный шаг, только после
  того, как проверка вперёд покажет пользу, и только с вашего OK;
- не даёт прогнозов и гарантий. Все цифры — это измерения на прошлых данных.

| `Set NICS_DATA_URL and NICS_DATA_KEY first` | откройте новое окно после `setx` |
| `Could not find a version that satisfies the requirement pyyaml` | старая версия установки: `git pull`, потом снова `scripts\windows\setup.bat` |
| `No module named 'torch'` | запущен не тот Python: используйте `.\venv\Scripts\python.exe` |
| `running scripts is disabled on this system` | не используйте `activate`, запускайте `.\venv\Scripts\python.exe` |
| `No champion yet` | сначала шаг 3 |
| `MT5 initialize failed` | откройте терминал MT5 и войдите в счёт |
| `Another cycle is running` | если ночной цикл точно не идёт, удалите `self_learn.lock` |
| мало места на диске | цикл хранит 3 последних снимка данных (до ~300 МБ каждый), старые удаляет сам; кеш Dukascopy в `data\cache\` около 100 МБ |

| `403: wrong NICS_BACKUP_KEY` | ключ бэкапа неверный, повторите шаг 11.1 |

| `FAILED: ... table(s) failed` в `logs\db_backup.txt` | пришлите мне этот журнал; недокачанная копия осталась как `...partial` |

## 11. Бэкап базы на ноутбук (полный, каждую ночь)

Копия всей боевой базы NICS Trading (все 88 таблиц: свечи, сканы, сигналы, пользователи,
история `market_history_public` и остальное) скачивается на ноутбук. На сервере ничего
не меняется: выгрузка только читает. Секретные значения из `app_secrets` (ключи, токены,
пароли) в копию **не попадают**, вместо них стоит `__REDACTED__`.

**Один раз:**
1. n8n → workflow «[00 OPS] Database Backup Export» → нажмите **Execute** у узла
   «Create or Show Backup Key». В результате будет `db_backup_key` — скопируйте его.
2. `git pull`, потом первый бэкап вручную (10–30 минут, ~200–400 МБ):
   ```
   .\venv\Scripts\python.exe scripts\db_backup.py
   ```
   Скрипт спросит ключ: вставьте его (символы не видны) и нажмите Enter. Он сохранится
   сам, как через `setx`, и ночной бэкап будет его брать. Адрес сервера задавать не
   нужно. В конце строка `OK C:\NICS\backups\db\<дата_время>  rows=...`.
3. Ночной бэкап в 04:15: `scripts\windows\install_tasks.bat` (заново, он добавит задачу
   «NICS DB backup»; если ноутбук ночью выключен — бэкап сделается при включении).

**Где лежит:** `C:\NICS\backups\db\<дата_время>\` — `manifest.json` (сколько строк в
каждой таблице), `schema\` (структура), `data\<таблица>.jsonl.gz` (данные). Хранятся
14 последних, старые удаляются сами. Недокачанная копия называется `...partial` и не
считается. Журнал: `logs\db_backup.txt`. Для второй копии скопируйте папку на внешний
диск или в облако.

**Восстановить** (в пустую базу, никогда не в боевую):
```
.\venv\Scripts\python.exe scripts\db_restore.py C:\NICS\backups\db\<дата_время> --out restore.sql
psql "<строка подключения к ПУСТОЙ базе>" -v ON_ERROR_STOP=1 -1 -f restore.sql
```
После восстановления впишите в `app_secrets` настоящие ключи (или выпустите новые).

## 12. NICS Language: замер скорости ноутбука (один раз, 2 минуты)

NICS Language — наша языковая модель с нуля: свой токенизатор, своя архитектура, свои
веса. Перед обучением нужно один раз замерить, сколько токенов в секунду этот ноутбук
обучает и сколько выдаёт при ответе. Данные и интернет для замера не нужны.

1. Откройте папку `C:\NICS\nics-ai-lab` в проводнике.
2. Дважды щёлкните `scripts\windows\bench_language.bat`. Окно само обновит код и
   запустит замер. Лучше закрыть на это время тяжёлые программы.
3. Когда появится строка `Report saved to ...`, пришлите мне текст из окна или файл
   `logs\bench_text.json`.

По этим цифрам я уточню сроки обучения в плане. Обучение этим шагом не запускается.
